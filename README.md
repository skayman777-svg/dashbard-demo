# Business Metrics Dashboard

A sales dashboard for a home-goods retailer (demo company, generated data). It combines data from a CRM,
accounting, ad accounts and marketplace exports on one page:

- revenue, orders, average order value, gross margin, ad spend share (ACoS) and new customers, each compared
  with the previous period;
- daily revenue with the previous period as a dashed line;
- plan vs actual by month;
- revenue by sales channel, channel table with share, AOV, margin, ACoS and conversion;
- top products and a data sources panel with sync status;
- period and channel filters, light and dark themes.

**Live demo:** https://skayman777-svg.github.io/dashbard-demo/

Plain HTML + D3.js, no paid BI tools. The same layout can be fed from Google Sheets, Excel exports,
a database or APIs.
